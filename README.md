# BIT 2118 – Scientific Computing

## Project Overview

The project demonstrates the application of numerical methods and scientific computing techniques to mathematical and real-world problems.

## Project Objectives

- Apply scientific computing concepts using Python.
- Perform numerical calculations using scientific libraries.
- Examine how changes in input parameters affect results.
- Interpret outputs and graphs.
- Apply computational methods to real-world problems.

## Technologies Used

- Python
- NumPy
- SciPy
- Matplotlib
- Visual Studio Code
- Git and GitHub

## Repository Structure

| Folder/File | Description |
|---|---|
| `code/` | Contains Python programs for the assigned tasks. |
| `docs/` | Contains documentation for each task. |
| `images/` | Contains graphs related to the tasks. |
| `outputs/` | Contains program outputs for the tasks. |
| `.gitignore` | Specifies files Git should ignore. |
| `README.md` | Provides an overview of the project. |

## How to Run the Programs

1. Install Python.
2. Install the required libraries:

   ```bash
   pip install numpy scipy matplotlib
   ```

3. Clone or download the repository.
4. Open the project in Visual Studio Code.
5. Navigate to the `code/` folder.
6. Select the Python file for the task and run it.

## Documentation

Each task's documentation covers:

1. Inputs and Mathematical Operations
2. Parameter Change and Results
3. Explanation of the Output
4. Related Real-World Case, including assumptions, input data, output and interpretation.
